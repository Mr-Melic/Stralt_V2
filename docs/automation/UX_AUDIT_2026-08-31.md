## Theme findings

### Visual hierarchy

WorldExploration already has a real Dofus top strip (name, level, Map #, leftover XP, region, Doka, IAP). GameFlow painted a second opaque `z-[9000]` bar over it that read `selectedCharacterProp` from `App.tsx` — that prop is never set — so players saw **0 / 100 XP**, a dummy **Map** / **Zone**, a **Blood** bar at 0, and a dead **XP / RWD** pill. This run moved realm tools (Items / Board / Feats / Bosses) into a stone cluster under the live HUD.

Identity drift: `DESIGN.md` asks for Space Grotesk / Inter / OKLCH tokens. Launch title is Arial; `index.css` is Baloo 2 / Saira; most screens still use raw hex. Do not “fix” that with a SaaS token sweep.

### Action discoverability

First map has no “click a floor tile to walk” or “colored whirlpools are exits.” Combat Walk / Attack / End Turn / Nearest had no disabled reason (titles added). Attack Nearest stays mute until a spell is selected in Attack mode.

### Feedback / invalid actions

Cast failures (`Not enough AP/MP`, `invalid target`) go to the battle log, not a toast or a tile caption. Flee used a bare `window.confirm` (copy now names the Death Realm). Login failures were console-only (banner added).

### AP / MP / spell / enemy

Battle panel AP/MP orbs are correct (`maxBattleAp` / `maxBattleMp`). The stats-panel jewels still hardcode HP 100 / AP 6 / MP 4, so the jewel fill lies after the first level-ups. Enemy inspect exists on initiative chips; there is no persistent “this is the thing you are aiming at” chrome.

### Portals / rewards / death / HUD / modals / responsive

Dungeon portals label when nearby; rest / boss / colored / white sanctuary do not. Recap XP denominator is `level * 100` (draft `#108` also owns leftover XP). Death opens a defeat recap **and** unmounts the world into Game Over — two stacked answers to “what happened.” `<768px` is a hard block (`App.tsx` + `SmallScreenWarning`) even though DESIGN.md specifies 44px mobile targets.

## What this run changed (small, display-only)

1. Unmasked the live world HUD; renamed the Buff shop control to **Items**.
2. Game Over copy + stone frame: Death Realm, half HP, 20/40 penalties.
3. Defeat recap CTA no longer says “Respawn.”
4. Walk / Attack / Flee / End Turn / Nearest titles explain the block.
5. Selection left-rotate actually turns left.
6. Launch next-step sentence + login error banner.
7. Create / update toast tells the player to press **Play**.

Not implemented (need a human): death-flow unification, recap XP curve (overlap `#108`), first-run teaching, portal legend, jewel maxes, two-shop IA, version-forced re-login, small-screen policy.
