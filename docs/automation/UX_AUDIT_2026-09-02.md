## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip (name, level, Map #, leftover XP, region, Doka, cart). GameFlow keeps a pointer-events-none spacer plus an Items / Board / Feats / Bosses cluster at `z-9001` under the HUD. That cluster still collides with the live strip on mid-width tablets (`UX-HUD-TOOL-CLUSTER`).

Boss Rush room chip is still `#FF69B4` arcade pink under the header (`UX-BOSS-RUSH-PINK`). Dungeon depth uses carved crimson. Do not “fix” leftover-XP purple — it matches `--dofus-xp-color` and Dofus XP chrome.

Identity drift (`UX-IDENTITY-FONT-DRIFT`): DESIGN.md asks for Space Grotesk / Inter / OKLCH. Launch title measures Arial; `index.css` is Baloo 2 / Saira. Next new screen only. No repo-wide hex sweep.

### Action discoverability

First map still has no coach (`UX-ONBOARD-FIRST-MAP`). Champion forge still hides starting 100 HP / 10 AP / 5 MP (`UX-CREATE-NO-STATS`). Overworld spell dock looked live after SpellFooter was folded into `BattleUIPanel`; this run disables slots out of battle and restores the fight-first hover.

Buy Doka after #258 is a four-beat off-game loop (email → Mollie → admin approval → 120-char redeem). The QR still sits above the form while copy says submit email first (`UX-GAMEKEY-STEP-ORDER`). This run adds `IAP_SHOP_STEPS` constants only — **not** wired into `DokaGameKeyShop` because older open PRs already own that file.

### Feedback / invalid actions

Cast failures on the canvas still go to the battle log (`UX-CAST-FAIL-FEEDBACK`). Challenge fail now names the broken rule. GameKey paste-trim, status poll, and shop how-to wiring stay **OPEN** (`UX-GAMEKEY-*`) so this PR does not overwrite #261 / #279 / #284 / #286 / #290.

### AP / MP / spell / enemy

Battle orbs still use `maxBattleAp` / `maxBattleMp`. Side-panel jewels still use `vitalsOrbCaps` (`UX-VITALS-ORB-MAX` resolved). Enemy inspect still lives on initiative chips; there is still no persistent “this is the thing you are aiming at” chrome. The world **Enemies** button opens `EnemyRegister` lore the engine does not run (`UX-ENEMY-REGISTER-LORE` / PXA-2026-09-01-001). Do not implement the register as truth.

### Portals / rewards / death / HUD / modals / responsive

Dungeon portals label when nearby; rest / boss / colored / white sanctuary / Death Realm exits do not (`UX-PORTAL-LEGEND`). Recap leftover XP is truthful (`UX-RECAP-XP-CURVE`). Combat death still unmounts the world into Game Over; lava death still fires the root recap and auto-enters the realm in 1.5s (`UX-DEATH-DUAL-MODAL`). `<768px` offers Continue anyway; there is still no stacked HUD (`UX-SMALL-SCREEN-HARD-BLOCK`). Changelog still appears only after II re-login (`UX-VERSION-FORCE-RELOGIN`); this run refreshed the four bullets so the *next* bump is not a 2025 feature list. `APP_VERSION` was **not** bumped (that would force every player through II again).
